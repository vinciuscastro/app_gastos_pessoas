# app_gastos_pessoas

É um aplicativo móvel desenvolvido em Flutter, voltado para o controle de gastos pessoais. Nosso objetivo é facilitar o controle financeiro dos usuários, oferecendo uma experiência simples e intuitiva para o gerenciamento de despesas.

## Funcionalidades
- [x] Cadastro de transações: o usuário pode cadastrar suas transações, informando o valor, a data e a descrição da despesa.
- [x] Listagem de transações: o usuário pode visualizar todas as transações cadastradas, com informações como valor, data e descrição.
- [ ] Cálculo de despesas: o aplicativo calcula automaticamente o total de despesas cadastradas, exibindo o valor total gasto.

## Tecnologias
- Flutter
- Dart
- SQLite

## Instalação
1. Clone o repositório
```bash
git clone https://github.com/vinciuscastro/app-gastos-pessoais
```

2. Acesse a pasta do projeto
```bash
cd app-gastos-pessoais
```

3. Instale as dependências
```bash
flutter pub get
```

4. Execute o projeto
```bash
flutter run
```
